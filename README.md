# FixPC Toolkit

FixPC Toolkit is a modular Windows diagnostic and repair tool.

## Features

### Hardware Diagnostics
- CPU / RAM / Disk analysis
- SMART health
- Battery health classification
- Temperature monitoring (with fallback)

### Network Diagnostics
- Smart adapter detection
- Wi-Fi SSID detection
- APIPA handling (no false positives)
- DNS + TCP validation (no ICMP false alarms)

### Repair
- Safe automated network repair actions

### Reports
- Clean HTML diagnostic report
